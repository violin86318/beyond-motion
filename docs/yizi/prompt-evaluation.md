# 一字美学提示词 v2 评估方案

状态：离线候选，尚未通过真实模型样张验证。此文档只定义评估方法，不构成新增生图授权。

## 优化方向

旧提示词把「东方」「留白」「纸感」「山水」写成固定结果，容易让模型忽略汉字本身，把字与背景画成两层。v2 将不变的系列规则与每期主题简报分开：先锁定唯一汉字，再描述字形结构、意象如何进入笔画或负形；配色、材质和背景根据字义变化。作品内只允许出现主题字，日期、题跋、署名、印章文字及AI说明交由网页排版，减少错字和署名混乱。

## 离线检查

每次准备运行前检查：

- `{char}` 必须是单个已核实汉字；主题简报的 `{meaning}`、`{visual_concept}`、`{palette}` 均非空。
- 编译结果中不保留花括号变量，不新增英文版本或同义字，不让模型重新选字。
- 提示词版本、最终文本、简报及哈希一并保存；同一任务只提交一次，结果未知时找回该次结果，不重画。
- 输出规格由实际执行器设置；提示词不虚构模型能力、像素规格或“零错误”保证。

离线检查只能证明文本与变量正确，不能证明字形渲染或审美结果。

## 真实样张审核

真实评估需要单独有明确的样张费用范围。选一个字形结构清楚、意象关系具体的brief，提交一次并保留实际供应商路由、模型、请求引用、实际像素与结果。不得为做A/B对照而额外重画旧版。评审时逐项记录：

1. 字的部件、结构是否正确，第一眼能否读出指定汉字。
2. 意象是否进入笔画、转折、连接或负形，是否与字义相关。
3. 字形是否是完整、足够醒目的第一主体，关键笔画没有被裁切。
4. 构图、留白、明暗和色彩是否服务主题，而非重复固定配色。
5. 细节是否清楚且有层次，有无模糊、断笔、伪笔画、乱码或无关符号。
6. 画内是否只出现指定主字，没有日期、署名、题跋、印章文字或水印。

任一硬缺陷即拒绝，不以总分抵消。可选的五项 0–4 分评分只用于比较与记录；“单项至少3、总分至少16”仍是待确认提案，不得自动替代用户判断。
